Práctica de Ingeniería de Software

Descripción

 Programa en C que registra eventos de
 diferentes equipos mediante arreglos y una
 matriz. El programa cuenta los intentos
 fallidos de cada equipo y los clasifica como
 Normal o Sospechoso utilizando un umbral X = 3.


Compilación

gcc codigo.c -o codigo


Ejecución

./codigo
