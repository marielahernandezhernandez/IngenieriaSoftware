Manager de un grupo musical (K-pop)

Este proyecto consiste en un programa hecho en C para administrar un grupo musical de K-pop.

En él se pueden realizar diferentes acciones con los integrantes del grupo, como cambiar al líder, asignar canciones, recuperar energía y realizar conciertos.

¿Cómo ejecutar el programa?

Para compilarlo, utiliza:

gcc -Wall -Wextra -o manager manager.c

Para ejecutarlo:

./manager

Archivo del proyecto

- "manager.c": contiene el código del programa.
